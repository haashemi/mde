# MDE

A simple markdown editor with a live preview. Use it at [mde.haashemi.dev](https://mde.haashemi.dev); it works offline too.

  <source media="(prefers-color-scheme: dark)" srcset="./public/screenshots/wide-dark.png">

</picture>

## Self-hosting

```sh
pnpm install && pnpm build
pnpx serve ./dist
```

## Contributing

This project doesn't accept issues or pull requests. It's in the public domain, so you're free to fork it, copy it, or do whatever you want with it.
